# Java-Tic-Tac-Toe (Java Swing)

This is a personal Java project to build a Tic-Tac-Toe game using Swing.

## Features
- Graphical user interface using Jframe and Jpanel
- Startup menu with Start, Rules, and Exit options
- 2-player mode (X always starts)
- Planned 1-player mode against a bot

## Project Status
Work in progress.

## Tech Used
- Java
- Java Swing
